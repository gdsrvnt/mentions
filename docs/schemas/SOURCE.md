# Vendored plugin schema

`plugin.schema.json` is a copy of the Cursor plugin schema.

Source: `https://github.com/cursor/plugins/blob/118e73b/schemas/plugin.schema.json`

Revision: `118e73b` (2026-10-12).

`scripts/validate-plugin.mjs` checks `.cursor-plugin/plugin.json` against this file. It uses the draft-07 keywords the schema actually contains, so the check runs without a package install.
